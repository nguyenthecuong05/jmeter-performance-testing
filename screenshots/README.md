# Screenshot Checklist

Add screenshots from your own actual test run here. Suggested filenames:

1. `01-thread-group.png` — Thread Group showing 5 users, 5-second ramp-up, and 2 loops.
2. `02-http-requests-assertions.png` — the two HTTP GET samplers and response-code assertions.
3. `03-view-results-tree.png` — actual sample results.
4. `04-summary-report.png` — actual summary metrics.
5. `05-github-actions.png` — completed GitHub Actions run (if using the cloud workflow).
6. `06-html-dashboard.png` — actual JMeter HTML report.

Do not create fake screenshots or represent sample numbers as measured results.
